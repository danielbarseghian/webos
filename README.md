# How to run locally
1. Clone the repo
```bash
    git clone https://github.com/danielbarseghian/webos.git
```

2. Run the website
Go to the root of the folder and run
### Linux / macOS

```bash
python3 -m http.server
```

### Windows

```bash
python -m http.server
```

make sur you have python installed
